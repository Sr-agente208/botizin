# 🤖 SAKURA-BOT

Bot para WhatsApp feito em Node.js

---

## 🚀 Instalação no Termux

termux-setup-storage

pkg update -y && pkg upgrade -y

pkg install git -y
pkg install nodejs-lts -y
pkg install ffmpeg -y
pkg install wget -y
pkg install tesseract -y

cd /sdcard
git clone https://github.com/suportebasedigital9854-ux/SAKURA-BOT.git

cd/sdcard/SAKURA-BOT
sh start.sh
